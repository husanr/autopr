🔒 Privacy Policy

Last updated: April 20, 2026

Overview

AutoPR - AI Pull Request Assistant ("AutoPR") is a Chrome extension that helps developers generate Pull Request descriptions and perform AI-powered code reviews on GitHub.

We take your privacy seriously. This policy explains what data we collect, how we use it, and how we protect it.

What We DO NOT Collect

  • We do not collect any personal information
  • We do not track your browsing activity
  • We do not store or transmit your code to any server we control
  • We do not use analytics or tracking services
  • We do not sell or share any user data

Data Stored Locally

The following data is stored only on your device using Chrome's local storage API (chrome.storage.sync):

  • API Configuration — Your AI provider API key, base URL, and selected model
  • Usage Count — Monthly usage counter for free tier limits
  • Plan Type — Whether you are using the Free or Pro plan

This data is never sent to any server except the AI provider you configure (e.g., OpenRouter, OpenAI, DeepSeek).

How the Extension Works

When you use AutoPR on a GitHub Pull Request page:

  1. The extension reads the code changes (diff) from the current PR page
  2. The diff is sent directly to your chosen AI provider's API
  3. The AI response is displayed in the extension panel

The diff data is not stored, logged, or transmitted to any server other than your configured AI provider.

Host Permissions

The extension requests permission for https://github.com/* solely to:

  • Detect when you are on a GitHub Pull Request page
  • Inject the AutoPR panel into the page
  • Read code changes (diff) from the PR for AI analysis

Third-Party Services

You may configure AutoPR to use third-party AI services:

  • OpenRouter — Privacy Policy
  • OpenAI — Privacy Policy
  • DeepSeek — Privacy Policy

When you use these services, your code diff is sent directly to their APIs. Their respective privacy policies apply.
